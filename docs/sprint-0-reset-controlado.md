# Sprint 0 — Reset Controlado

## Objetivo

Criar uma nova base organizada para o desenvolvimento do projeto UPA.

## Justificativa

O projeto será reiniciado em uma estrutura limpa para evitar acúmulo de arquivos antigos, conflitos de implementação e inconsistências entre documentação, backend, frontend e design.

## Decisão

Foi adotado um reset controlado, mantendo o projeto anterior como backup e criando uma nova pasta chamada UPA_RESTART.

## Estrutura criada

- backend/
- frontend/
- docs/
- wireframes/
- assets/
- README.md
- .gitignore

## Stack oficial

- Front-end: React + Vite
- Back-end: Django + Django REST Framework
- Banco de dados: SQLite
- Autenticação: JWT
- Versionamento: Git/GitHub

## Critério de conclusão

A Sprint 0 será considerada concluída quando a estrutura inicial estiver criada, versionada e documentada.
