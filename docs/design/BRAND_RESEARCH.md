# Takion Campus — pesquisa preliminar de nome

Pesquisa em 10/10/2026. Nome de trabalho recomendado: **Takion Campus**, com assinatura **by Takion Software**. O composto comunica a organização da vida acadêmica; Archive restringe a ideia a acervo e Atlas é menos específico. [Atlas já é utilizado pela Faria](https://www.faria.org/solutions/curriculum-management/) para gestão curricular.

Buscas web separadas pelos compostos exatos “Takion Campus”, “Takion Archive” e “Takion Atlas” não identificaram uma plataforma acadêmica com esses nomes nos resultados consultados. Isso **não comprova disponibilidade jurídica**. Há usos tecnológicos do radical Takion:

- [Takion Technologies](https://www.takiontechnologies.com/about/), software de negociação financeira.
- [Takion Systems](https://takionsystems.com/), desenvolvimento de aplicações. Não foi verificada relação com a marca do autor deste projeto.
- [Takion.be](https://takion.be/en/), automação residencial.

O [INPI pePI](https://busca.inpi.gov.br/pePI/jsp/Base_pesquisa.jsp) permite pesquisa anônima, mas a sessão de consulta expirou. O [novo portal](https://servicos.busca.inpi.gov.br/marcas) não retornou resultados acessíveis. A [WIPO Global Brand Database](https://branddb.wipo.int/) apresentou desafio ALTCHA. **Nenhum resultado registral foi validado.** [INPI](https://www.gov.br/inpi/pt-br/servicos/marcas/guia-basico/guia-basico) e [WIPO](https://www.wipo.int/en/web/global-brand-database) orientam pesquisar marcas anteriores e registros nacionais.

Takion Campus é adotado como identidade deste projeto independente de portfólio e demonstração. Não se declara registro, exclusividade ou vínculo oficial com uma instituição educacional. Uma eventual exploração comercial requer concluir a pesquisa registral. Alterar o radical para Archive ou Atlas não eliminaria os usos existentes de Takion.
