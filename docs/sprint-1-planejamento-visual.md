# Sprint 1 — Planejamento Visual e Escopo Fechado

## Objetivo

Definir a identidade visual, o escopo inicial, os módulos principais e os wireframes base do projeto UPA.

## Proposta do UPA

O UPA é uma proposta de modernização de um portal acadêmico, com foco em melhorar a experiência do aluno por meio de uma interface moderna, responsiva, acessível e organizada.

## Problema Identificado

O portal acadêmico atual possui aparência antiga, baixa hierarquia visual, navegação pouco intuitiva e experiência visual desagradável para as novas gerações de estudantes.
